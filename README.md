## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **No Phone Required** | Register with just a Threema ID — no phone number or email needed |
| **E2E Encryption** | All messages, calls and files protected by Threema's own E2E encryption |
| **Local Contact Storage** | Contacts stored locally on your device — never uploaded to servers |
| **Anonymous Polls** | Create group polls without revealing individual voter identities |
